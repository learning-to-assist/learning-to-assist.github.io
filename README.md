# Learning to Assist: Collaborative VLAs for Implicit Human-Robot Collaboration

Project page for the CoRL 2026 paper by Leo Xu, Letian Li, Alex Cuellar, and Michael Hagenow
([arXiv](https://arxiv.org/abs/2606.12475)).

## Local preview

From the repository root:

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
